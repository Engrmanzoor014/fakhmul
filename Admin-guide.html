Create your database and connect it to your site — step by step

1️⃣
Create a Firebase Project
Go to console.firebase.google.com → Click Add Project → Name it fakhmul-store → Disable Google Analytics (not needed) → Click Create.
2️⃣
Enable Firestore Database
In Firebase Console → Build → Firestore Database → Create Database → Choose Start in test mode (we'll secure it later) → Select your region → Done.
3️⃣
Register Your Web App
In Firebase Console → Project Settings (⚙️ gear icon) → Your Apps → Click </> Web → App nickname: fakhmul-web → Register App → Copy the config object shown.
4️⃣
Add Firebase to your HTML files
Add this to the <head> of index.html, admin-dashboard.html, admin-orders.html, admin-customers.html, and admin-analytics.html:
index.html — <head> section 
<!-- Firebase SDK -->
<script type="module">
  import { initializeApp } from 'https://www.gstatic.com/firebasejs/10.7.0/firebase-app.js';
  import { getFirestore, collection, getDocs,
           addDoc, updateDoc, deleteDoc, doc,
           onSnapshot, query, orderBy }
    from 'https://www.gstatic.com/firebasejs/10.7.0/firebase-firestore.js';

  // ← Paste YOUR Firebase config here
  const firebaseConfig = {
    apiKey:            "YOUR_API_KEY",
    authDomain:        "fakhmul-store.firebaseapp.com",
    projectId:         "fakhmul-store",
    storageBucket:     "fakhmul-store.appspot.com",
    messagingSenderId: "YOUR_SENDER_ID",
    appId:             "YOUR_APP_ID"
  };

  const app = initializeApp(firebaseConfig);
  const db  = getFirestore(app);
  window.db = db; // make available globally
</script>

Connect Admin Panel to Firebase

Replace localStorage with real Firestore read/write calls

Replace the localStorage.getItem / setItem calls in each admin page with these Firebase equivalents. Here are the four patterns you'll need:

Pattern 1 — Load all products (replaces localStorage.getItem) 
async function loadProducts() {
  const snapshot = await getDocs(collection(db, 'products'));
  products = snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));
  renderProducts(); // your existing render function
}
Pattern 2 — Save a product (replaces localStorage.setItem) 
async function saveProduct(productData) {
  if (editingId) {
    // UPDATE existing
    await updateDoc(doc(db, 'products', editingId), productData);
  } else {
    // CREATE new
    await addDoc(collection(db, 'products'), productData);
  }
  await loadProducts(); // refresh list
  showToast('✅ Product saved!');
}
Pattern 3 — Delete a product 
async function deleteProduct(productId) {
  await deleteDoc(doc(db, 'products', productId));
  await loadProducts();
  showToast('🗑️ Product deleted');
}
Pattern 4 — Real-time orders listener (live updates) 
// This fires every time an order changes — no refresh needed
function listenToOrders() {
  const q = query(
    collection(db, 'orders'),
    orderBy('date', 'desc')
  );
  onSnapshot(q, (snapshot) => {
    orders = snapshot.docs.map(d => ({ id: d.id, ...d.data() }));
    renderTable();   // auto-updates the UI
    updateStats();
  });
}
✅
Pro tip: Use onSnapshot for orders and customers — it gives you real-time updates. Use getDocs for products since they change less often.

Image Uploads with Cloudinary

Let admins upload product photos directly from the browser

1️⃣
Create a free Cloudinary account
Go to cloudinary.com → Sign up free → Dashboard shows your Cloud Name. Note it down.
2️⃣
Create an unsigned upload preset
Settings → Upload → Upload Presets → Add Upload Preset → Set Signing Mode to Unsigned → Save. Note the Preset Name.
3️⃣
Add image upload to admin-dashboard.html
Replace the image URL input with this file picker:
admin-dashboard.html — image upload function 
async function uploadImage(file) {
  const CLOUD_NAME   = 'your-cloud-name'; // ← replace
  const UPLOAD_PRESET = 'fakhmul-products'; // ← replace

  const formData = new FormData();
  formData.append('file', file);
  formData.append('upload_preset', UPLOAD_PRESET);
  formData.append('folder', 'fakhmul');

  const res = await fetch(
    `https://api.cloudinary.com/v1_1/${CLOUD_NAME}/image/upload`,
    { method: 'POST', body: formData }
  );
  const data = await res.json();
  return data.secure_url; // ← permanent image URL
}

// In your form: replace the text input with:
// <input type="file" accept="image/*"
//   onchange="handleImageSelect(this)">

async function handleImageSelect(input) {
  const file = input.files[0];
  if (!file) return;
  showToast('⏳ Uploading image…');
  const url = await uploadImage(file);
  document.getElementById('fImg').value = url;
  previewImg();
  showToast('✅ Image uploaded!');
}

4️⃣
Add a netlify.toml config file
Create this file in your root folder to protect your admin pages:
netlify.toml 
# Redirect all /admin pages — add password protection
[[redirects]]
  from = "/admin-*"
  to   = "/admin-:splat"
  status = 200

# Force HTTPS
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options        = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy        = "strict-origin-when-cross-origin"

Custom Domain Setup

Get fakhmul.pk or fakhmul.com pointing to your Netlify site

1️⃣
Buy your domain
For Pakistan: pknic.net.pk for .pk domains (official registry) or namecheap.com for .com domains (~$10/year). Search for fakhmul.pk or fakhmul.com.
2️⃣
Add domain to Netlify
In Netlify dashboard → Site Settings → Domain Management → Add Custom Domain → Enter fakhmul.pk → Netlify will show you DNS records to add.
3️⃣
Update DNS records at your registrar
In your domain registrar's DNS settings, add these records (Netlify shows exact values):
DNS Records to add at your registrar 
Type   Name    Value
────────────────────────────────────────
A      @       75.2.60.5       # Netlify IP
CNAME  www     fakhmul.netlify.app

# DNS changes take 24-48 hours to propagate worldwide
# Netlify auto-provisions free SSL (https) once DNS is set
4️⃣
Enable HTTPS (automatic)
Netlify automatically provisions a free SSL certificate via Let's Encrypt once your DNS is pointed correctly. Go to Site Settings → HTTPS → Verify DNS → Enable HTTPS. Your site will be https://fakhmul.pk 🎉

Security Hardening

Protect your admin panel and customer data

🔐 Upgrade Admin Login
Replace the simple password check with Firebase Authentication. Use signInWithEmailAndPassword() so credentials aren't stored in HTML source code. Enable MFA for extra security.
🛡️ Firestore Security Rules
Replace "test mode" with real rules so only your admin account can read/write orders and products. Customers can only read products.
🔒 Environment Variables
Move Firebase config from HTML into Netlify Environment Variables. Go to Netlify → Site Settings → Environment Variables. Never commit API keys to GitHub.
🚫 Rate Limiting
Firebase already limits requests. For the admin login page, keep the 3-attempt lockout from Phase 1. Consider adding reCAPTCHA to contact and newsletter forms.
📋 HTTPS Only
Netlify enforces HTTPS automatically. Add Strict-Transport-Security header in netlify.toml to force all traffic to HTTPS even if someone types http://.
🗂️ Regular Backups
Export your Firestore data monthly using the "Export" button in Firebase Console. Store backups in Google Drive. For products, use the JSON export in Phase 2 admin panel.
Firebase Firestore Security Rules (production) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Products: anyone can read, only admin can write
    match /products/{productId} {
      allow read:  if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'admin@fakhmul.pk';
    }

    // Orders: only admin can read/write
    match /orders/{orderId} {
      allow read, write: if request.auth != null
                         && request.auth.token.email == 'admin@fakhmul.pk';
    }

    // Subscribers: anyone can create (sign up), only admin reads
    match /subscribers/{subId} {
      allow create: if true;
      allow read, delete: if request.auth != null
                          && request.auth.token.email == 'admin@fakhmul.pk';
    }
  }
}
🚨
Never commit your Firebase API key to a public GitHub repo. Use Netlify Environment Variables or a .env file that's listed in .gitignore.
